# Recording plan and shot list

## Preparation

- [ ] Start from a clean browser session and close unrelated tabs/notifications.
- [ ] Confirm the deployed URL and API are reachable before recording.
- [ ] Select one bundled synthetic sample, or a real shop video with documented permission.
- [ ] Check that the sample is visibly labelled synthetic when applicable.
- [ ] Confirm which AI mode/provider is active; capture evidence without exposing keys, headers, tokens, or private logs.
- [ ] Make one complete run before recording. Do not assume a previous ad belongs to the current run.
- [ ] Prepare a backup recording or screenshots for a transient network failure; label any prerecorded footage accurately.
- [ ] Set display scaling/browser zoom so text is readable; use a 16:9 recording canvas if the portal permits.

## Shot list

| Time | Shot | Must be visible | Avoid |
|---|---|---|---|
| 0:00–0:20 | Landing page / Try-it | Product promise and project name | Long intro animation |
| 0:20–0:45 | Sample and brief | Synthetic label or consented-source status; rights confirmation; product offer | Personal phone numbers or private video metadata |
| 0:45–1:20 | Pipeline progress | Director findings, cut-out step, live progress | API keys, raw authorization headers |
| 1:20–1:55 | Game and report | Playable interaction, end card, actual quality report | Calling a mock run a live model test |
| 1:55–2:25 | Share outputs | Only assets actually produced in this run | Stale or unrelated output files |
| 2:25–2:45 | Safety / why panel | Rights, safety, audit explanation, synthetic label | Private consent record |
| 2:45–3:00 | Closing | Reel2Play name and attribution | Unsupported claims or unverified metrics |

## Audio / narration

- Speak at a steady pace; keep the narration aligned with the visible action.
- If the recording has no voiceover, add concise captions that do not claim more than the footage proves.
- Do not include copyrighted music from the source Reel. The original video audio should be muted/removed in the workflow.

## Final quality check

- [ ] Video is between 2:45 and 3:00 unless the portal specifies otherwise.
- [ ] No blank page, loading spinner, error toast, or accidental desktop notification remains in the final cut.
- [ ] All UI text and the game are readable at normal playback size.
- [ ] Synthetic examples remain labelled synthetic.
- [ ] No credentials, personal data, private consent details, or unapproved shop assets appear.
- [ ] Every spoken technical claim is backed by something visible or by a saved, redacted run record.
- [ ] Attribution is visible: `Built with Muse Spark Open`.
