# Final submission checklist

**Deadline noted in the project brief:** 4 November 2026, 9:00 PM ET / 5 November 2026, 7:00 AM Pakistan time. Re-check the official portal because deadlines or timezone display can change.

## Project and demo

- [ ] Public demo URL opens in a fresh browser session.
- [ ] API health and one complete demo flow are verified on the deployed environment.
- [ ] Three-minute video is uploaded and the URL opens without sign-in.
- [ ] Video accurately labels synthetic samples and mock runs.
- [ ] All screenshots, assets, and shop videos are synthetic or permission-cleared.
- [ ] `Built with Muse Spark Open` attribution is visible.

## Technical claims

- [ ] Record exactly which models/providers ran in the final demo.
- [ ] Do not claim live Muse Spark Open, Muse Glimmer, or SAM 3.1 execution without run evidence.
- [ ] Do not claim 30-video real-shop evaluation until it has actually run and the report exists.
- [ ] Do not present synthetic CI metrics as customer outcomes.
- [ ] Confirm all links, exported files, and visible output assets belong to the final demo run.

## Rules and team

- [ ] Re-read the current official hackathon rules and submission instructions.
- [ ] Confirm the exact track and required deliverables in the portal.
- [ ] List every person who materially contributed, following the team-size rules.
- [ ] Resolve any overlapping-team/entry question with the organizers if applicable.
- [ ] Confirm source repository visibility and required README/license/commit-history rules.
- [ ] Include demo video, source repository, live demo, and written description wherever requested.

## Security and packaging

- [ ] No `.env`, API key, token, service-account file, private key, or credential appears in the ZIP.
- [ ] No private consent record, customer contact, or unapproved video appears in the ZIP.
- [ ] No `node_modules`, virtual environment, build cache, or local database dump is included.
- [ ] Inspect the final ZIP listing before sharing.
- [ ] Keep a private backup of the exact submitted ZIP and video.

## Final sign-off

- [ ] All placeholders in `SUBMISSION_WRITEUP.md` are replaced or removed.
- [ ] Every public claim is supported by visible demo evidence or a saved redacted record.
- [ ] Submission portal shows a successful final submission/confirmation.
